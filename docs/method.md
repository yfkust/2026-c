问题一
保留视觉特征的脑电降噪模型

事件分段 → 伪迹识别 → 自适应小波降噪 → ERP 提取 → P300 相关波形拟合

输出：各条件、各电极的视觉响应曲线及特征

问题二
视觉刺激到头皮 EEG 的神经计算模型

LGN 视觉输入 → 方向选择性特征 → Wilson–Cowan 神经群 → 头皮电位正向模型

输出：左右三角刺激差异的形成机制及特征表示

问题三
视觉认知与决策宏观模型

视觉感知 → 工作记忆与匹配 → 神经网络协同 → 决策积累 → 应答

输出：EEG 时间序列、认知状态、应答与反应时间的联合验证

一、题目要求、实验设计及数据核验
1. 三个问题的内在关系

问题一要求分别处理两个视觉实验，提取 F3、Fz、F4 三个电极的有效视觉响应，尤其关注约 250–500 ms 的 P300 相关成分，并在去除眨眼、运动等伪迹时保留反映视物形状的信号特征。问题二要求建立 LGN—大脑皮层—头皮脑电之间的计算关系，解释左右三角刺激响应的差异。问题三则进一步加入海马体等潜在信息来源，描述由视觉感知、识别到作出应答的认知过程。

三问实际上对应同一系统的三个层次：问题一从观测数据中获得可信的响应，问题二解释响应如何产生，问题三解释这些响应如何参与认知决策。因此，第一问得到的 ERP 模板、左右刺激差异和个体参数，应当直接用于第二问的模型校准；第二问的神经状态和头皮观测模型，则应当作为第三问的基础，而不是三问各自建立互不相关的模型。

2. 必须区分的两种实验
项目一
已知目标位置

目标出现前已经知道它的位置，只需要等待目标出现并完成应答。

主要考察定向注意与预期条件下的视觉响应。

项目二
未知目标位置

目标出现前不知道其左右位置，只知道需要识别的三角形方向，随后进行目标搜索与匹配。

主要考察形状识别、目标匹配及其认知负荷。
