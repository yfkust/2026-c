## 问题一：保留视觉特征的脑电降噪与 ERP 拟合

这一问适合作为整篇论文的实证基础。建议采用“常规预处理作为对照、自适应小波作为主要降噪方法、条件相关响应作为保护约束”的方案。补充材料也提出了 ICA、眼电回归、小波阈值和任务相关成分分析等方法，但它们应根据现有三电极数据的可用信息进行选择，而不是全部堆叠。

### 1. 建立信号分解模型

设第 $i$ 次实验、第 $c$ 个电极在刺激后时间 $t$ 的观测信号为：

$x_{i,c}(t)=s_{y_i,c}(t)+a_{i,c}(t)+n_{i,c}(t) \tag{1}$

其中，$s_{y_i,c}(t)$ 是与视觉提示条件 $y_i$ 相关的神经响应，$a_{i,c}(t)$ 是眼动、眨眼、心电或运动等伪迹，$n_{i,c}(t)$ 是其余背景噪声。$y_i=-1$ 或 $+1$，分别表示左、右视觉提示。

模型目标不仅是使 $a+n$ 变小，还要尽量维持条件响应 $s_{-1}$ 与 $s_{+1}$ 之间可重复的差异。由于只有三个额叶电极，不能假设可以将眼电、神经活动等多个独立源完全分离。

### 2. 事件对齐与基础预处理

首先从原始通道 1–3 读取 Fz、F3、F4，不把设备已经解混的 Decon 通道作为主要结果。以 VisCue 从零转为 $-1/+1$ 的样本为提示起点，截取刺激前 200 ms 至刺激后约 800–1000 ms，形成大小为“试次数 × 3 通道 × 时间采样点”的数据张量。

基础滤波建议采用 0.1–30 Hz 作为初始方案，并与 0.5–30 Hz 进行敏感性比较，因为高通截止频率过高可能改变较慢的 ERP 成分。只有在原始功率谱显示明显工频干扰时才添加 50 Hz 陷波。刺激前 $[-200,0]$ ms 用于基线校正。

预处理应按实验项目、提示方向分别管理事件。对目标呈现阶段，另行使用第 9 通道建立目标锁定的 epoch，不要与提示锁定的响应混为一谈。

### 3. 设计保留形状差异的自适应降噪

普通阈值降噪主要依据幅度大小判断信号和噪声，但视觉响应较弱，可能被一同削弱。可以首先在训练试次中分别求取左、右条件的平均 ERP：

$\bar{x}_{y,c}(t)= \frac{1}{N_y}\sum_{i:y_i=y}x_{i,c}(t)$

再计算左右差异模板：

$d_c(t)=\bar{x}_{+1,c}(t)-\bar{x}_{-1,c}(t) \tag{2}$

将训练试次随机分成两半，分别计算 $d_c^{(1)}(t)$ 和 $d_c^{(2)}(t)$。只有在两半数据中重复出现、方向一致的时频成分，才作为候选视觉特征加以保护。这样可以降低把随机噪声误判为形状差异的风险。

主降噪方法可采用离散小波变换，对不同尺度、时间窗口设置自适应阈值：

$\tilde{w}_{j,k} = \operatorname{sgn}(w_{j,k}) \max(|w_{j,k}|-\lambda_{j,k},0) \tag{3}$

$w_{j,k}$ 表示第 $j$ 个小波尺度、第 $k$ 个时间位置的系数，$\lambda_{j,k}$ 是该位置的阈值。普通区域的阈值可以利用基线噪声估计；在训练数据验证过的视觉响应区域，采用较小阈值，以减少有效信号衰减。

保护窗口可先考察刺激后 150–600 ms，而不是只保留 250–500 ms，因为早期视觉响应与较晚的认知相关电位都可能携带信息。最终保护区域应由训练数据中的稳定性分析确定。

伪迹部分采用分层策略。明显饱和的片段先标记或剔除；高幅度瞬态采用稳健阈值或局部修正；ECG 可以作为检验心电相关干扰的辅助通道。ICA 可以列入对照实验，但三个额叶电极且没有独立眼电通道时，自动 ICA 不能保证准确识别眨眼成分。

### 4. ERP 提取、拟合与左右差异表示

对处理后的信号按条件平均：

$ERP_{q,y,c}(t) = \frac{1}{N_{q,y}} \sum_{i\in(q,y)}\hat{s}_{i,c}(t) \tag{4}$

其中 $q$ 表示项目一或项目二。每个项目分别得到左、右提示下 F3、Fz、F4 的六条平均曲线。

在刺激后 250–500 ms 内，提取正向峰的候选振幅和潜伏期，随后可使用高斯叠峰模型：

$ERP(t)=b_0+b_1t+ \sum_{m=1}^{M} A_m\exp\left[-\frac{(t-\mu_m)^2}{2\sigma_m^2}\right] \tag{5}$

$A_m$ 为峰值贡献，$\mu_m$ 为峰中心潜伏期，$\sigma_m$ 为峰宽，$b_0+b_1t$ 表示残余基线。峰数 $M$ 应保持较小，通过拟合残差或交叉验证选择，避免把噪声拟合成多个生理成分。

需要注意，题面描述的经典 P300 主要位于中央—顶区，而提供的数据只有 F3、Fz、F4。因此，可以分析额叶观测到的 250–500 ms 任务相关正向 ERP，但不能仅凭这三个电极证明已经完整观测到经典中央—顶区 P300。

左右差异建议从以下三个维度提取：各电极 ERP 的左右差分曲线、F3 与 F4 的侧化差异，以及正峰振幅和潜伏期的条件差异。尤其值得研究的特征是：

$LI_y= \frac{A_{F3,y}-A_{F4,y}} {|A_{F3,y}|+|A_{F4,y}|+\epsilon} \tag{6}$

这里 $LI_y$ 是额叶侧化指标，$\epsilon$ 防止分母为零。需要通过实际数据检验其方向和稳定性，不能预先认定左三角必然激活左侧或右侧额叶。

### 5. 降噪效果如何验证

不能仅凭“波形变平滑”证明方法有效。应比较原始信号、普通带通滤波、常规小波、适用条件下的 ICA，以及提出的保护特征小波方案。

主要评价指标包括：重复试次 ERP 的分半一致性、P300 相关峰的潜伏期稳定性、左右条件差异的可重复性、基于处理后特征的交叉验证分类表现，以及伪迹相关残余。没有真实干净 EEG 时，基于刺激前后能量计算的 SNR 只能作为代理指标，不能视为真实信噪比。

建议使用 LDA 或线性 SVM 检验左右提示的可区分性。所有保护窗口、阈值和分类器参数都只能在训练集上估计，测试试次不能参与构建 ERP 模板，否则容易产生信息泄漏。

## 1. Comprehensive Mathematical Modeling Process

## 1.1 The Noise-Signal Separability Hypotheses

To design a feature-preserving denoising framework, we must define the statistical properties of both the signal and the noise across space and time. Let the continuous measured voltage tensor of the three scalp channels be $\mathbf{V}(t) = [V_{Fz}(t), V_{F3}(t), V_{F4}(t)]^T \in \mathbb{R}^{3 \times 1}$. We establish three core mathematical hypotheses:

1. **Temporal Phase-Locking Hypothesis:** The visual sensory feature matrix and the subsequent cognitive P300 component are phase-locked to the trigger timestamp $T_m$ defined by Channel 8 (`VisCue`). This means that across trials $m=1, 2, \dots, M$, the cognitive signal sequence satisfies:
   $$\mathbb{E}[S_c(T_m + \tau)] = \mathcal{A}_c(\tau)$$ 
   where $\mathcal{A}_c(\tau)$ is a deterministic function of the post-stimulus lag $\tau$.
2. **Spatial Asymmetry Projection Hypothesis:** Biological artifacts like eye blinks ($E(t)$) project uniformly onto the prefrontal/frontal cortex array due to their relative distance from the occipital poles. Thus, they appear as in-phase components:
   $$\mathbf{E}(t) = [1, 1, 1]^T \cdot e_{blink}(t)$$ 
   Conversely, visual features linked to spatial shape (left vs. right triangle) generate asymmetric activation patterns between the left and right hemispheres (channels $F3$ and $F4$), manifesting as a differential signal.
3. **Ergodicity of Background Noise:** Environmental noise $\xi_c(t)$ and background electromyographic (EMG) muscle signals are zero-mean, independent, identically distributed (i.i.d.) random variables relative to the stimulus onset:
   $$\lim_{M \to \infty} \frac{1}{M}\sum_{m=1}^M \xi_c(T_m + \tau) = 0$$ 

## 1.2 Step-by-Step Mathematical Formulation of the Pipeline

## Step 1: Phase-Preserving Forward-Backward Digital Filtering

To isolate the frequency range of the P300 component ($0.5\text{--}20\text{ Hz}$) without altering its temporal position (latency), we apply a zero-phase 4th-order Butterworth digital filter. A standard causal IIR filter introduces a frequency-dependent phase delay, which shifts the calculated latency of the peak. We bypass this by executing a forward pass followed by a time-reversed backward pass.

Given the filter coefficients $b_k$ and $a_m$, the forward-pass sequence $v_f[t]$ is given by:
$$v_f[t] = \frac{1}{a_0} \left( \sum_{k=0}^{P} b_k V_c[t-k] - \sum_{m=1}^{Q} a_m v_f[t-m] \right)$$ 
The forward sequence is then reversed in time ($v_f^*[t] = v_f[N-t]$), passed through the same digital structure, and reversed again to yield the zero-phase output $v_{zp}[t]$. This operation squares the filter magnitude profile while completely canceling out the phase response:
$$H_{zp}(z) = H(z) \cdot H(z^{-1}) \implies \vert{}H_{zp}(\omega)\vert{} = \vert{}H(\omega)\vert{}^2, \quad \angle H_{zp}(\omega) = 0$$ 

## Step 2: Trigger-Based Matrix Window Partitioning (Epoching)

Let $t_k = k \cdot \Delta t = \frac{k}{f_s}$ represent the discrete time grid sampled at $f_s = 256\text{ Hz}$. The algorithm scans Channel 8 (`VisCue`) to construct the discrete set of trigger indices $\mathcal{K}$:
$$\mathcal{K} = \{ k \mid \text{VisCue}[k] \neq 0 \;\land\; \text{VisCue}[k-1] = 0 \}$$ 
For every trigger index $k_m \in \mathcal{K}$ representing the $m$-th trial, we extract a temporal slice spanning the interval $[-200\text{ ms}, +800\text{ ms}]$. This corresponds to a discrete range from $k_m - N_{\text{pre}}$ to $k_m + N_{\text{post}} - 1$, where:
$$N_{\text{pre}} = \text{round}(0.2 \times 256) = 51 \text{ points}, \quad N_{\text{post}} = \text{round}(0.8 \times 256) = 205 \text{ points}$$ 

Each trial forms an independent matrix $\mathbf{\tilde{X}}_m \in \mathbb{R}^{256 \times 3}$:
$$\mathbf{\tilde{X}}_m = \begin{bmatrix}  v_{zp}[k_m - 51, Fz] & v_{zp}[k_m - 51, F3] & v_{zp}[k_m - 51, F4] \\ \vdots & \vdots & \vdots \\ v_{zp}[k_m + 204, Fz] & v_{zp}[k_m + 204, F3] & v_{zp}[k_m + 204, F4] \end{bmatrix}$$ 

## Step 3: Local Feature-Preserving Drift Subtraction

Instead of utilizing spatial decomposition methods that can eliminate subtle lateralized visual features, we apply an independent trial-level baseline correction. The mean voltage calculated during the pre-stimulus period ($n \in [0, 50]$) acts as a local estimate of slow ocular drift and DC offset for that specific trial. This value is subtracted from the entire trial length:
$$\mathbf{\mu}_m = \frac{1}{51} \sum_{n=0}^{50} \mathbf{\tilde{X}}_m[n, :] \in \mathbb{R}^{1 \times 3}$$ 
$$\mathbf{X}_m[n, :] = \mathbf{\tilde{X}}_m[n, :] - \mathbf{\mu}_m, \quad n \in [0, 255]$$ 

## Step 4: Multi-Trial Linear Cross-Sectional Convergence

We separate the trial matrices $\mathbf{X}_m$ into two discrete subsets based on the shape condition: $\mathcal{M}_{\text{Left}} = \{m \mid \text{VisCue}[k_m] = -1\}$ and $\mathcal{M}_{\text{Right}} = \{m \mid \text{VisCue}[k_m] = 1\}$. We then compute the grand average for each condition across trials. This step forces uncorrelated background noise to decay toward zero while preserving the phase-locked P300 component:
$$\mathbf{\bar{X}}_{\text{Left}} = \frac{1}{\vert{}\mathcal{M}_{\text{Left}}\vert{}} \sum_{m \in \mathcal{M}_{\text{Left}}} \mathbf{X}_m, \quad \mathbf{\bar{X}}_{\text{Right}} = \frac{1}{\vert{}\mathcal{M}_{\text{Right}}\vert{}} \sum_{m \in \mathcal{M}_{\text{Right}}} \mathbf{X}_m$$

## 1.3 Asymmetric Mathematical Optimization Fitting Engine

The P300 component appears as a positive wave in the $250\text{--}500\text{ ms}$ post-stimulus interval (corresponding to index points $n \in [115, 179]$). Because the activation phase of a neural population rises at a different rate than its deactivation phase, we replace the standard symmetric Gaussian model with an **Asymmetric Skewed Gaussian Optimization Model**:

$$f(t; A, \mu, \sigma_0, \alpha) = A \cdot \exp\left( -\frac{(t - \mu)^2}{2 \left(\frac{\sigma_0}{1 + \alpha(t - \mu)}\right)^2} \right)$$ 

To fit this non-linear function to the clean empirical array $\bar{V}_{Fz}(t)$, we use the Levenberg-Marquardt algorithm to minimize the sum of squared residuals:
$$\min_{A, \mu, \sigma_0, \alpha} \sum_{i} \left[ \bar{V}_{Fz}(t_i) - f(t_i; A, \mu, \sigma_0, \alpha) \right]^2$$

import numpy as np
import scipy.io as sio
from scipy.signal import butter, filtfilt
from scipy.optimize import curve_fit

def run_problem_1_pipeline(mat_file_name):
    """
    Executes the comprehensive feature-preserving denoising and parameter 
    fitting pipeline for Problem 1 using a specific .mat file dataset.
    """
    # =========================================================================
    # STEP 1: PARSE MATLAB DATA STREAM AND EXTRACT CHANNELS
    # =========================================================================
    raw_mat = sio.loadmat(mat_file_name)
    # Automatically locate internal array variable name (ignoring system header keys)
    data_key = [key for key in raw_mat.keys() if not key.startswith('__')][0]
    data_matrix = raw_mat[data_key] # Expected internal dimensions: [TimePoints, 10]
    
    # Isolate mandatory operational channels (0-indexed parsing)
    fz_raw = data_matrix[:, 0]
    f3_raw = data_matrix[:, 1]
    f4_raw = data_matrix[:, 2]
    vis_cue = data_matrix[:, 7]  # Channel 8: Visual triggers (-1, 0, 1)
    timestamps = data_matrix[:, 9] # Channel 10: Clock
    
    sfreq = 256.0
    
    # =========================================================================
    # STEP 2: PHASE-PRESERVING BUTTERWORTH IIR BANDPASS FILTER
    # =========================================================================
    nyquist = 0.5 * sfreq
    low_cut, high_cut = 0.5, 20.0
    # Compute 4th-order filter coefficients
    b, a = butter(4, [low_cut / nyquist, high_cut / nyquist], btype='band')
    
    # Zero-phase forward-backward array filtering
    fz_clean = filtfilt(b, a, fz_raw)
    f3_clean = filtfilt(b, a, f3_raw)
    f4_clean = filtfilt(b, a, f4_raw)
    filtered_block = np.stack([fz_clean, f3_clean, f4_clean], axis=1) # [Time, Channels]
    
    # =========================================================================
    # STEP 3: VISUAL-CUE LOCKED SEGMENTATION & EPOCH CORRECTION
    # =========================================================================
    pre_stim_pts = int(0.2 * sfreq)   # 51 points (-200ms)
    post_stim_pts = int(0.8 * sfreq) # 205 points (+800ms)
    total_epoch_pts = pre_stim_pts + post_stim_pts
    
    # Generate continuous time array for plotting models (-200ms to +800ms)
    epoch_time_vector = np.linspace(-200.0, 800.0, total_epoch_pts)
    
    # Identify trigger point indices where stimulus appears
    cue_onsets = np.where((vis_cue[:-1] == 0) & (vis_cue[1:] != 0))[0] + 1
    
    left_triangle_epochs = []
    right_triangle_epochs = []
    
    for onset_idx in cue_onsets:
        # Check boundary conditions
        if (onset_idx - pre_stim_pts < 0) or (onset_idx + post_stim_pts > len(data_matrix)):
            continue
            
        cue_identity = vis_cue[onset_idx]
        # Slice out time segment [256, 3]
        epoch_segment = filtered_block[onset_idx - pre_stim_pts : onset_idx + post_stim_pts, :].copy()
        
        # Local baseline protection subtraction (using the 51 pre-stimulus points)
        baseline_profile = np.mean(epoch_segment[0:pre_stim_pts, :], axis=0)
        corrected_segment = epoch_segment - baseline_profile
        
        if cue_identity == -1:    # Left Triangle Condition
            left_triangle_epochs.append(corrected_segment)
        elif cue_identity == 1:   # Right Triangle Condition
            right_triangle_epochs.append(corrected_segment)
            
    # Convert lists to 3D tensors: [Trials, TimePoints, Channels]
    left_tensor = np.array(left_triangle_epochs)
    right_tensor = np.array(right_triangle_epochs)
    
    # =========================================================================
    # STEP 4: LINEAR CROSS-SECTIONAL GRAND AVERAGING
    # =========================================================================
    # Fz is located at index 0 in our stacked block
    fz_grand_avg_left = np.mean(left_tensor[:, :, 0], axis=0)
    fz_grand_avg_right = np.mean(right_tensor[:, :, 0], axis=0)
    
    # =========================================================================
    # STEP 5: ASYMMETRIC SKEWED GAUSSIAN NON-LINEAR OPTIMIZATION
    # =========================================================================
    # Isolate empirical data bound strictly to the 250ms - 500ms window
    p300_fit_window = np.where((epoch_time_vector >= 250.0) & (epoch_time_vector <= 500.0))[0]
    t_fit_samples = epoch_time_vector[p300_fit_window]
    
    y_empirical_left = fz_grand_avg_left[p300_fit_window]
    y_empirical_right = fz_grand_avg_right[p300_fit_window]
    
    # Define Asymmetric Skewed Gaussian Mathematical Formula
    def asymmetric_skewed_gaussian(t, A, mu, sigma0, alpha):
        # Prevent division by zero errors across iterations
        denominator = 1.0 + alpha * (t - mu)
        denominator = np.where(denominator == 0, 1e-5, denominator)
        sigma_t = sigma0 / denominator
        # Enforce boundary constraint layers natively via clipping bounds
        sigma_t = np.clip(sigma_t, 5.0, 300.0)
        return A * np.exp(- (t - mu)**2 / (2 * sigma_t**2))
    
    # Optimization initial parameters seed: [Amplitude, Center Latency, Base Scale, Skew]
    initial_seed = [np.max(y_empirical_left), 350.0, 60.0, 0.001]
    
    # Run Levenberg-Marquardt parameter estimation
    popt_left, _ = curve_fit(asymmetric_skewed_gaussian, t_fit_samples, y_empirical_left, p0=initial_seed, maxfev=50000)
    popt_right, _ = curve_fit(asymmetric_skewed_gaussian, t_fit_samples, y_empirical_right, p0=initial_seed, maxfev=50000)
    
    # Compute fitting profiles across the target window
    fit_curve_left = asymmetric_skewed_gaussian(t_fit_samples, *popt_left)
    fit_curve_right = asymmetric_skewed_gaussian(t_fit_samples, *popt_right)
    
    # Return metrics dictionary for visualization plotting and results reporting
    return {
        "time": epoch_time_vector,
        "left_raw_avg": fz_grand_avg_left,
        "right_raw_avg": fz_grand_avg_right,
        "t_fit": t_fit_samples,
        "left_fit_curve": fit_curve_left,
        "right_fit_curve": fit_curve_right,
        "params_left": popt_left,   # [A, mu, sigma0, alpha]
        "params_right": popt_right   # [A, mu, sigma0, alpha]
    }
