# 项目任务书

## 1. 项目目标与证据边界

本项目建立一条可复现的“原始 EEG → 有效视觉响应 → 低阶生成机制 → 认知与行为验证”链路。最终交付不是单纯分类器，而是同时满足数据可信、数学可解释、计算可实现和结论不过界的建模论文与代码。

当前文档是阶段 0 的需求基线，不代表任何候选模型已经通过实验。

### 共同输入

- 四份 MATLAB v5 数据，每份含 10 个通道，采样率 256 Hz；
- 原始 EEG：Fz、F3、F4；辅助记录：ECG、VisCue、第 9 通道、TimeStamp；
- 设备处理通道仅用于对照；
- 原始赛题、整合解题思路、六篇 EEG 方法文献及参考代码。

### 共同约束

- 三个额区电极不能唯一识别深部源或高分辨率皮层分布；
- 左右提示、目标空间位置、点击方向和三角形方向不能未经核验互换；
- 所有特征选择、模板估计和超参数选择必须限制在训练数据；
- 无干净 EEG 真值时，代理 SNR 不能称为真实 SNR；
- A/B 身份未确认，只称“A/B 两组记录”。

## 2. 问题一：保留视觉事件成分的去噪与响应拟合

### 2.1 目标与赛题要求

分别处理 Task-1 和 Task-2 的原始 Fz、F3、F4，在抑制眨眼、运动、饱和和背景噪声的同时保留左右三角提示相关信息；提取各点位有效视觉响应，拟合曲线，并审慎分析 250–500 ms 的候选 P300/任务相关正向成分。

### 2.2 输入与输出

输入：原始三通道 EEG、VisCue、时间戳、ECG 和经核验的 trial 事件表。

输出计划：

- 质量掩码、有效/无效 trial 清单及拒绝原因；
- cue 锁定的单试次数据、左右条件 ERP 和不确定性；
- 候选正峰的时间窗均值、峰值、潜伏期、面积和侧化特征；
- 曲线拟合及拟合误差；
- 去噪方法对照、半模拟保真性和留出条件判别结果。

### 2.3 候选方法及取舍

| 层级 | 候选方法 | 采用条件 | 主要风险/成本 |
|---|---|---|---|
| 基线 | 质量掩码 + 温和零相位带通 + 基线校正 + 稳健平均 | 必做，建立可解释下限 | 滤波边界效应；不能恢复饱和样本 |
| 主候选 | 训练折内学习的时频/小波掩码或软阈值 | 半模拟和留出数据均显示保真收益 | 易把模板泄漏到测试集；PyWavelets 当前未安装 |
| 对照 | 普通小波、适用条件下的三通道 ICA、设备 Decon | 仅作消融或对照 | 三通道 ICA 可识别性弱；Decon 不是真值 |
| 高级备选 | 带质量掩码的低秩/稀疏结构分解 | 基线明显不足且收益可验证时 | 参数多、计算成本和过拟合风险高 |

优先采用最小可验证方案。整合稿提出的结构化稳健分解不默认作为主模型，需先证明其相对简单基线有稳定增益。

### 2.4 指标

- 数据质量：饱和比例、异常 trial 比例、各条件有效 trial 数；
- 降噪：基线段稳健方差、伪迹残余、半模拟恢复 RMSE/相关性；
- 保真：分半 ERP 一致性、峰潜伏期稳定性、左右差异复现性；
- 判别：嵌套或严格留出交叉验证的 balanced accuracy、ROC-AUC、置乱基线；
- 拟合：留出时间点/试次误差、残差结构和参数稳定性。

### 2.5 假设与验收标准

假设：视觉事件相关响应相对 cue 具有有限的跨试次时间锁定性；强伪迹与目标响应在幅值、时间或跨试次结构上并非完全不可分。两项假设均需用数据检验。

验收标准：

1. 四份数据均能用统一规则生成可审计事件表和质量报告；
2. 处理仅基于通道 1–3，Decon 只作对照；
3. 至少一个简单基线和一个候选保特征方法在同一划分上比较；
4. 半模拟恢复、留出保真和标签置乱三类验证均有实际输出；
5. 对 P300、眼动混杂和饱和不可逆性明确限定结论。

## 3. 问题二：视觉刺激—LGN—皮层—头皮 EEG 生成模型

### 3.1 目标与赛题要求

建立可计算的生成模型，描述视觉形状输入经 LGN/皮层有效状态到三通道头皮 EEG 的映射；解释左右刺激条件差异，并输出可判别特征。模型必须把生理机制假设与三通道 EEG 直接支持的事实分开。

### 3.2 输入与输出

输入：问题一的清洁单试次/ERP、质量权重、左右提示标签和 trial 划分；参数化左右三角刺激。

输出计划：

- 视觉输入特征（方向、构型或镜像关系）；
- 低维兴奋—抑制状态及有效源电流；
- `3 × K` 的有效头皮投影和三通道预测波形；
- 观测特征、机制参数特征及左右生成似然/判别分数；
- 参数可辨识性、灵敏度、消融和镜像反事实结果。

### 3.3 候选模型及取舍

- 最小主线：参数化视觉构型 → 少量形状选择性驱动 → Wilson–Cowan 型低维神经群 → 线性有效投影 + 观测噪声。
- 条件升级：只有低维模型不能解释预注册的波形特征且留出性能受益时，才加入低阶神经场或多个空间模态。
- 不采用：无个体 MRI/电极全覆盖条件下的唯一源定位；无法由 400 个 trial 支撑的高维自由神经场。

### 3.4 指标、假设与验收标准

指标：留出 EEG RMSE/相关性/负对数似然、左右生成判别、参数恢复、局部灵敏度、多初值稳定性、消融增益与复杂度。

关键假设：左右三角构型造成不同的有效输入；低维神经群足以表示三通道可见的主要动态；头皮观测在当前尺度可用固定或分层有效投影近似。它们是可检验建模假设，不是实测解剖结论。

验收标准：

1. 完整给出状态方程、观测方程、参数边界和估计过程；
2. 与无构型、无抑制或更简单响应核至少一个竞争模型比较；
3. 在未参与拟合的 trial/记录上验证波形与左右证据；
4. 报告不可辨识参数组合，不以单次最优解证明机制唯一；
5. 所有深部结构表述保持“机制假设/有效状态”范围。

## 4. 问题三：视觉认知宏观模型与行为验证

### 4.1 目标与赛题要求

在问题二生成机制上区分早期视觉响应与后续记忆、匹配、注意和决策过程，并结合真实应答验证。认知信号终点需相对行为事件定义，错误、缺失、超时和运动响应分别处理。

### 4.2 输入与输出

输入：问题二的感觉/皮层有效状态、问题一事件表、目标阶段和应答阶段标记、反应时间及正确性状态。

输出计划：

- 感觉、记忆模板、比较/证据和决策的低维状态；
- Task-1/Task-2 的共享参数与必要差异参数；
- 仅使用应答前固定前缀的 EEG 与行为预测；
- 反应时间分布、选择概率和错误/缺失/超时分类；
- 去记忆、去注意、无反馈等竞争模型比较。

### 4.3 候选方法及取舍

主候选是“感觉—记忆/模板—比较状态空间 + 简化证据累积”。仅当行为数据量和错误数足够时才拟合完整 DDM；当前数据中明确错误/缺失事件可能极少，复杂 DDM 的误差机制很可能不可识别。

运动响应后的 EEG 不得用于预测同一次应答。Task-2 的提示方向、目标位置与点击方向分别建模，避免标签泄漏。

### 4.4 指标、假设与验收标准

指标：固定前缀的 EEG 预测误差、RT MAE/负对数似然、选择预测 balanced accuracy、校准、竞争模型信息准则或留出似然。

验收标准：

1. 明确 trial 时间线和每类行为状态的编码规则；
2. 早期感觉状态继承问题二，而非重新任意定义；
3. 行为模型只使用决策时点之前的信息；
4. 至少比较一个无记忆/无反馈简化模型；
5. 数据不足时报告不可估计项，不填补虚构错误或超时样本。

## 5. 总体验收

最终项目需形成统一的数据字典、不可泄漏的划分、三问连续的数据接口、可重复命令、实际生成的全部图表和一篇结论范围与证据一致的论文。当前阶段仅完成需求和计划，不判定任何模型有效。
