## 1.1 The LGN-to-Cortex Spatial Injection Model

The human visual pathway maps spatial inputs onto the brain symmetrically but in reverse (contralaterally). A left triangle stimulus activates the right cerebral hemisphere first, while a right triangle activates the left.

Let the cortex be parameterized as a 2D grid workspace $\mathbf{x} = (x, y) \in \Omega$. The subcortical input current injected from the LGN into the cortical sheet is modeled as a localized spatial Gaussian distribution driven by Channel 8 (`VisCue`):

$$I_{\text{LGN}}(\mathbf{x}, t) = \gamma(t) \cdot \exp \left( -\frac{\Vert{}\mathbf{x} - \mathbf{x}_{\text{target}}\Vert{}^2}{2\sigma_{\text{input}}^2} \right)$$ 

Where the spatial injection target coordinates $\mathbf{x}_{\text{target}}$ depend on the visual configuration:
$$\mathbf{x}_{\text{target}} = \begin{cases} (-x_0, y_0), & \text{if VisCue} = -1 \;\text{(Left Triangle maps to Right Brain Region)} \\ (+x_0, y_0), & \text{if VisCue} = +1 \;\text{(Right Triangle maps to Left Brain Region)} \end{cases}$$ 
The term $\gamma(t)$ is a temporal envelope scaling factor that mirrors the early sensory input arrival window ($0 \le t \le 150\text{ ms}$).

## 1.2 Spatiotemporal Cortical Neural Field Partial Differential Equation (PDE)

Following the structural hint in **Figure 9**, cortical neural networks process items using organized patterns of interconnected, feature-sensitive neuron groups. We model this local collective behavior using a spatial continuity extension of the **Wilson-Cowan Equations**.

Let $u(\mathbf{x}, t)$ represent the average membrane potential of an excitatory neural population at coordinate $\mathbf{x}$ and time $t$. The system dynamics follow this non-linear integro-differential equation:

$$\tau \frac{\partial u(\mathbf{x}, t)}{\partial t} = -u(\mathbf{x}, t) + \int_{\Omega} W(\mathbf{x}, \mathbf{x}') \cdot f\big[u(\mathbf{x}', t)\big] d\mathbf{x}' + I_{\text{LGN}}(\mathbf{x}, t)$$ 

Isolating the variables and components:

- **$\tau$**: The characteristic relaxation time constant of the neural membrane ($\sim 10\text{ ms}$).
- **$f[v] = \frac{1}{1 + \exp(-\beta(v - \theta))}$**: The non-linear Sigmoid activation transfer function representing the population firing rate curve, parameterized by threshold $\theta$ and gain factor $\beta$.
- **$W(\mathbf{x}, \mathbf{x}')$**: The spatial connectivity kernel. It models a classic "Mexican Hat" lateral interaction pattern (short-range excitation combined with long-range surround inhibition):
  $$W(\mathbf{x}, \mathbf{x}') = A_{\text{exc}} \exp\left(-\frac{\Vert{}\mathbf{x}-\mathbf{x}'\Vert{}^2}{2\sigma_{\text{exc}}^2}\right) - A_{\text{inh}} \exp\left(-\frac{\Vert{}\mathbf{x}-\mathbf{x}'\Vert{}^2}{2\sigma_{\text{inh}}^2}\right)$$ 

## 1.3 Volume Conduction Projection Model (Cortex to Head Surface)

Scalp electrodes do not record membrane potentials directly. Instead, they capture extracellular currents that reach the scalp via volume conduction through the brain, skull, and scalp tissues.

Mathematically, this forward conversion is modeled by treating cortical active regions as distribution layers of current dipoles. The voltage $V_k(t)$ measured at electrode position $\mathbf{r}_k$ ($k \in \{F_3, F_z, F_4\}$) is computed using a spatial integration weighted by a geometric Green's function:

$$V_k(t) = \int_{\Omega} G(\mathbf{r}_k, \mathbf{x}) \cdot u(\mathbf{x}, t) d\mathbf{x} + \eta_k(t)$$ 

Using a simplified multi-sphere volume conduction profile, the transmission kernel $G$ relates inversely to the Euclidean distance between the scalp sensor and the cortical generator:
$$G(\mathbf{r}_k, \mathbf{x}) = \frac{1}{4\pi \sigma_{\text{tissue}} \Vert{}\mathbf{r}_k - \mathbf{x}\Vert{}^2}$$

## 2. Feature Representation: Differentiating Triangles

Because the inputs are lateralized, left and right triangle stimuli generate mirror-image cortical activation patterns across the hemispheres. To track this spatial difference, we extract a **额叶非对称性空间特征向量 (Frontal Asymmetry Spatial Feature Vector)** from the clean signals generated in Problem 1.

## 2.1 The Frontal Asymmetry Index (FAI) Time-Series

We construct a normalized asymmetry ratio comparing the voltage balances between the right frontal electrode ($F_4$) and left frontal electrode ($F3$):

$$FAI(t) = \frac{V_{F4}(t) - V_{F3}(t)}{V_{F4}(t) + V_{F3}(t) + \epsilon}$$ 

Where $\epsilon$ is a tiny floating stabilizer to avoid zero division. For a left triangle, right-hemisphere projection drives $V_{F4}(t) > V_{F3}(t)$, making the FAI positive. A right triangle reverses this pattern, yielding a negative FAI.

## 2.2 Core Structural Feature Matrix Mapping

To build a highly discriminative feature set for classification, we calculate three distinct metrics from the FAI during the cognitive processing window ($100\text{--}400\text{ ms}$):

1. **Integral Center of Gravity Mass ($\mathcal{F}_1$):**
   $$\mathcal{F}_1 = \int_{100}^{400} t \cdot FAI(t) dt$$ 
2. **Differential Spectral Entropy Energy ($\mathcal{F}_2$):** Calculates the variance of the FAI distribution over time to capture the wave's complexity:
   $$\mathcal{F}_2 = -\sum p(t) \ln p(t), \quad p(t) = \frac{FAI(t)^2}{\int FAI(\tau)^2 d\tau}$$ 
3. **Fz Phase-Locked Cross-Correlation Shift ($\mathcal{F}_3$):** Tracks how information flows from the midline to the lateral electrodes:
   $$\mathcal{F}_3 = \arg\max_{\delta} \int V_{Fz}(t) \cdot FAI(t + \delta) dt$$ 

The final feature array is represented as $\mathbf{\Phi} = [\mathcal{F}_1, \mathcal{F}_2, \mathcal{F}_3]^T \in \mathbb{R}^{3 \times 1}$, providing a clean, low-dimensional footprint that clearly separates left from right triangle responses.

# =========================================================================
def simulate_cortical_field(stimulus_direction, grid_size=32, total_steps=100):
    """
    Solves the 2D Spatiotemporal Wilson-Cowan Neural Field Equation.
    stimulus_direction: -1 for Left Triangle, +1 for Right Triangle
    """
    dt = 0.1
    tau = 1.0
    beta, theta = 4.0, 1.0
    
    # Initialize 2D Spatial Grid Coordinates
    x = np.linspace(-2.0, 2.0, grid_size)
    y = np.linspace(-2.0, 2.0, grid_size)
    X, Y = np.meshgrid(x, y)
    
    # Define LGN input injection targets based on lateralization rules
    # Left stimulus maps to right brain hemisphere (-1.0), and vice versa
    x_target = -1.0 if stimulus_direction == -1 else 1.0
    y_target = 0.5
    I_LGN = np.exp(-((X - x_target)**2 + (Y - y_target)**2) / (2 * 0.4**2))
    
    # Pre-calculate the 'Mexican Hat' spatial connectivity kernel matrix
    # short-range excitation + long-range surround inhibition
    W = np.zeros((grid_size, grid_size, grid_size, grid_size))
    for i in range(grid_size):
        for j in range(grid_size):
            dist_sq = (X - X[i,j])**2 + (Y - Y[i,j])**2
            W[i,j,:,:] = 2.0 * np.exp(-dist_sq / (2 * 0.3**2)) - 1.0 * np.exp(-dist_sq / (2 * 0.8**2))
            
    # State array initialization
    u = np.zeros((grid_size, grid_size))
    history = []
    
    # Run Finite-Difference Explicit Euler Iteration Loop
    for step in range(total_steps):
        # Compute population non-linear Sigmoid response
        firing_rate = 1.0 / (1.0 + np.exp(-beta * (u - theta)))
        
        # Spatial convolution integration over cortex sheet workspace
        spatial_integral = np.zeros((grid_size, grid_size))
        for i in range(grid_size):
            for j in range(grid_size):
                spatial_integral[i,j] = np.sum(W[i,j,:,:] * firing_rate) * (4.0 / grid_size**2)
                
        # Time-step update via Euler integration
        du = (-u + spatial_integral + I_LGN * np.sin(step * 0.05)) * (dt / tau)
        u += du
        history.append(u.copy())
        
    return np.array(history)

        fai_series = (f4_trace - f3_trace) / (f4_trace + f3_trace + 1e-6)

        feat_1 = np.sum(np.linspace(100, 400, len(fai_series)) * fai_series)

        feat_2 = np.var(fai_series)

        cross_corr = np.correlate(fz_trace, fai_series, mode='same')
        feat_3 = np.argmax(cross_corr)
        
        feature_matrix.append([feat_1, feat_2, feat_3])
