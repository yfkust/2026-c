# 项目开发计划

## 1. 总体数据流

```text
原始 MAT（只读）
  → 统一加载器、事件表、质量掩码、固定数据划分
  → 问题一：单试次清洁响应、ERP、候选 P300 和保真指标
  → 问题二：视觉构型输入、低维神经状态、有效头皮投影和生成特征
  → 问题三：感觉状态 + 记忆/匹配 + 证据累积、行为联合验证
  → 实际图表、结果表、论文与复现附录
```

问题一到问题二的接口不是“最佳分类准确率”，而是带质量权重和不确定性的单试次/ERP 响应。问题二到问题三的接口是可计算的早期感觉状态及其 EEG 观测映射，问题三不得重新拟合一个与问题二无关的感觉模块。

## 4. 数据划分与依赖原则

问题一采用每记录5个连续20-trial块的嵌套验证，邻接purge 1 trial且检查全部原始输入支持；严格共同质量集合比较方法。源记录到目标记录和跨任务迁移另报，不解释为跨被试泛化。QC统计、收缩增益、平滑参数、标准化和任何模型选择均在训练折内完成。具体规则及数据不足分支见 model_q1.md 第8节。任何后续模型必须继承其外层划分，并在训练内部重新拟合上游变换。

## 5. 主要风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 原始 EEG 长时间限幅 | trial 丢失、幅值偏差、不可逆信息损失 | 质量掩码、trial 权重、敏感性分析，不插值冒充恢复 |
| 三通道且位于额区 | 源定位和经典 P300 结论受限 | 使用低阶有效模型、限定术语、报告不可辨识性 |
| 第 9 通道语义不统一 | 行为标签错误、RT 偏差 | 按任务解析、人工抽样、操作性定义和敏感性检查 |
| A/B 身份未知 | 跨被试结论无依据 | 只称记录组，等待元数据或限制外推 |
| 模型链过长 | 参数累积、难以识别、计算成本高 | 每层先建立简单竞争模型，只有留出证据支持才升级 |
| 错误/漏答极少 | 完整 DDM 或错误机制不可估计 | 使用简化选择/RT 模型，报告数据不足 |
| 旧草稿代码矩阵方向错误 | 运行失败或错取通道 | 新加载器做结构断言，旧示例仅作思路参考 |
| 当前缺少 MNE/PyWavelets/h5py | 某些实现暂不可运行 | 阶段 2 冻结最小依赖后再安装；MAT v5 当前可由 SciPy 读取 |

## 7. 问题一设计决策（2026-09-24）

- 保留阶段0所有数据事实；100个边界完整窗口不等于100个质量合格trial。
- 基线先采用有限支持低通+基线，0.1/0.5Hz高通需满足缺口和折边界条件后才作敏感性，不默认在短窗上双向高通。
- 将欠明确的低秩/稀疏主模型降为后续备选；C1为可审计闭式候选，ρ=0允许退回B0，不宣称优于小波。
- 不插值恢复限幅；不利用Task-1未知行为语义；去噪变换不接受测试标签。
- 问题二同时接收波形和预处理算子；非因果输出不得直接作为问题三实时前缀输入。

## 8. 问题一事件/QC/划分前置实现（2026-09-24）

- 四记录原始 MAT 只读；`code/outputs/q1_audit/` 中 `events.csv`、`quality.csv`、`splits.json`、`summary.json`、`manifest.json` 为本次可重建审计输出。400 个 cue 的跨记录 `trial_id` 唯一；每记录 5 个连续 20-trial 外层测试块，训练相邻 purge 1 trial 后再检验原始支持交叠。
- 硬 QC 以实际精确 ±1000/越界与 ≥64 点完全平直段标记；软 QC 中位数/MAD 仅在外层训练折估计，κ=6 为候选，不是实验最优值。四记录硬通过数分别为 85、88、89、84；每个试次只出现一次的外层测试质量通过数分别为 82、86、83、83。它们是规则下的数据质量计数，不是 EEG 保真或模型表现。
- 保留第一次运行中 `trial_id` 碰撞的无效输出于 `code/outputs/q1_audit_superseded_bad_ids/`，仅用于追溯，任何后续分析不得读取。当前有效清单以 `code/outputs/q1_audit/manifest.json` 为准；若日后变更脚本或参数，应使用新输出目录重新运行并标记版本。
- 下一阶段仍需核验保留波形、Task-2 marker 语义、单位、A/B 身份、平直阈值和各折类别分布；未进行正式滤波、ERP、分类或参数优化。

## 9. 问题一 B0 最小实现（2026-09-24）

- `code/q1_preprocess.py` 复用有效 `Q1-audit-v1` 事件、质量和划分文件，并校验原始 MAT 哈希；FIR 只读取各 trial 的 576 点支持，输出三通道 512 点扩展波形并按 51 点基线裁剪为 307 点核心波形。任何硬故障 trial 拒绝，不插值；滤波器固定，不接受 cue 标签或训练模板。
- `code/outputs/q1_b0/epochs_b0.npz` 保存全部 346 个硬通过 trial 的 `epochs`、`trial_ids`、`record_ids`、`cue_sign`、`time_s`、基线常数、外层测试折与通过标志、FIR taps；`manifest.json` 保存配置、来源哈希、脚本/依赖版本。ERP 必须再按原 `splits.json` 的 `train_quality_pass`/`test_quality_pass` 选试次，不能把这 346 个波形直接混合求平均。外层测试质量通过总数仍为 334。
- 六个相关单元测试通过，合成高斯场景的幅值误差、峰时差、波形 NRMSE 和 50 Hz 残留均已实际计算，详见 PROGRESS。本次只是实现与契约验证，没有正式滤波保真、ERP 或分类结论。

## 10. 问题一 B0 频响与纯合成验证（2026-09-24）

- 冻结 `code/q1_b0_scenarios.json`（18场景、每场景100次、种子及每场景生成参数）；`code/q1_b0_validate.py` 只读取已存 B0 taps，调用既有 `b0_epoch`/`hard_mask`，不重做数据审计或预处理。`code/outputs/q1_b0_validation/` 保存频响CSV/JSON、逐试次/场景指标、已知干净波形、PDF/PNG图及环境清单；`paper/b0_validation.md` 保存方法与解释。
- 1–20 Hz 通带波动 0.022287 dB；30 Hz 为 −6.006887 dB 半幅点，不是 −3 dB；50/60 Hz 分别 −56.67/−62.44 dB。平滑高斯保留良好，但 AR(1)、低 SNR 混合、0.2Hz漂移及宽瞬态仍可严重污染输出；详细数值与限制在研究记录。
- 判定：B0 具备可复现的代码基线条件，**暂不具备无条件开展真实 ERP 推断的科学条件**。真实噪声/波形与质量选择诊断通过前不把模拟保真当成神经信号保真；正式 ERP、分类、C1 和问题二/三实验均未启动。频响/模拟均不使用真实 EEG 真值。
