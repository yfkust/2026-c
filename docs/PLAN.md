# 项目开发计划

## 1. 总体数据流

```text
原始 MAT（只读）
  → 统一加载器、事件表、质量掩码、固定数据划分
  → 问题一：单试次清洁响应、ERP、候选 P300 和保真指标
  → 问题二：视觉构型输入、低维神经状态、有效头皮投影和生成特征
  → 问题三：感觉状态 + 记忆/匹配 + 证据累积、行为联合验证
  → 实际图表、结果表、论文与复现附录
```

问题一到问题二的接口不是“最佳分类准确率”，而是带质量权重和不确定性的单试次/ERP 响应。问题二到问题三的接口是可计算的早期感觉状态及其 EEG 观测映射，问题三不得重新拟合一个与问题二无关的感觉模块。

## 4. 数据划分与依赖原则

阶段 1 必须先冻结划分策略。默认候选为按记录分层的 trial 级外层交叉验证；若评估跨记录泛化，则将整份记录留出。任何小波掩码、ERP 模板、异常阈值、标准化、时间窗微调和模型选择只能在外层训练数据内完成。A/B 身份未确认前，不把“留一 A/B”称为留一受试者验证。

## 5. 主要风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 原始 EEG 长时间限幅 | trial 丢失、幅值偏差、不可逆信息损失 | 质量掩码、trial 权重、敏感性分析，不插值冒充恢复 |
| 三通道且位于额区 | 源定位和经典 P300 结论受限 | 使用低阶有效模型、限定术语、报告不可辨识性 |
| 第 9 通道语义不统一 | 行为标签错误、RT 偏差 | 按任务解析、人工抽样、操作性定义和敏感性检查 |
| A/B 身份未知 | 跨被试结论无依据 | 只称记录组，等待元数据或限制外推 |
| 模型链过长 | 参数累积、难以识别、计算成本高 | 每层先建立简单竞争模型，只有留出证据支持才升级 |
| 错误/漏答极少 | 完整 DDM 或错误机制不可估计 | 使用简化选择/RT 模型，报告数据不足 |
| 旧草稿代码矩阵方向错误 | 运行失败或错取通道 | 新加载器做结构断言，旧示例仅作思路参考 |
| 当前缺少 MNE/PyWavelets/h5py | 某些实现暂不可运行 | 阶段 2 冻结最小依赖后再安装；MAT v5 当前可由 SciPy 读取 |

## 6. 当前最优下一步

阶段 1 的第一个任务：创建 `paper/model_q1.md`，冻结问题一的数学模型、事件协议、数据划分、基线和验证设计。验收标准是：每个公式的输入输出可映射到 `DATA_SPEC.md` 字段；所有数据驱动选择都有训练折边界；饱和、眼动混杂和 P300 表述有明确限制；方案能被最小代码实现而无需补充关键决策。
